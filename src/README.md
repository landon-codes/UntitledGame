# Untitled Game
This is a game where you play as Athena guiding Odysseus made in about a week. Enemies fall down from a grid, and your job is to help Odysseus avoid them.
Each turn you are given three randomly generated cards, which you can use to guide Odysseus.

## Running the project
You can either compile the project yourself (more reliable) or download a pre-compiled binary from the release page.

### Self Compilation
In order to compile the project, you will need to have .NET 10.0 installed on your machine.
1. Download the source code (using either git or downloading the source from the release)
2. Run `dotnet run` to build and run the program, or `dotnet build` to just build the program.

If you would like to have a release configuration, you can use the `dotnet publish` command.

### Downloading a Binary
1. Download the binary from the GitHub release page.
2. Extract the folder to a location on your computer.
3. Double tap the executable.

## Playing the Game
* When playing the game, you will use your mouse to click the cards.
* You have 4 lives, I just forgot to add text for them.
* You can click the escape key to close the game.
* The game does not have restarting functionality, so you will have to close and reopen the game to play again.
